## 最短获奖路径

严格按以下顺序推进，Dashboard、MCP 和复杂 UI 暂停：

1. 保持最新 Linux 四组与 Docker 回归；记录 Windows Application Control 阻断，不以关闭安全策略作为验证手段。
2. 在已通过的小型单仓差分与跨仓传递约束测试基础上，扩展更复杂依赖图与更多官方夹具。
3. 官方 Maple 框架已取得，三十九个选定 cjpm LLT 用例在两版通过，制品异常矩阵的时间戳波动已用测试副本隔离并在两版复核；补齐 Python 依赖后继续 cjpm 相关 HLT/LLT，再评估完整套件，不把子集通过写成整套通过。
4. 扩展基准覆盖；使用现有答辩稿完成攻击防护演示、主视频与无剪切验证视频。
