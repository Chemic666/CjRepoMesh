## 最短获奖路径

严格按以下顺序推进，Dashboard、MCP 和复杂 UI 暂停：

1. 扩充传递依赖冲突矩阵和兼容性差分报告。
2. 在现有 Linux 环境中补齐 Docker Compose 干净部署和 Linux 全量统一测试入口。
3. 运行可获得依赖的官方回归，并完成 Windows/Linux 差分证据。
4. 扩展基准覆盖并制作攻击防护演示、视频和答辩材料。
