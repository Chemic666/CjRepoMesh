## 最短获奖路径

严格按以下顺序推进，Dashboard、MCP 和复杂 UI 暂停：

1. 补齐既有 `[replace]` 在多仓场景下的强制替换端到端证据。
2. 增加来源记录及 `repo explain`，让选择、回退和替换可解释。
3. 加固并发发布/缓存填充，并补 Proxy TTL。
4. 由用户准备 Linux SDK/容器环境后验证 Docker Compose 干净部署。
5. 运行可获得依赖的官方回归，并完成 Windows/Linux 差分证据。
6. 最后制作 Benchmark、攻击防护演示、视频和答辩材料。
