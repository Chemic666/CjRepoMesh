# 仓库来源基线实施计划

**Goal:** 在最终仓库依赖集合已选定、下载任务尚未开始处，提供显式启用的CI来源准入检查。

**Design:** `CJREPOMESH_SOURCE_BASELINE` 指向独立审核的formatVersion=1来源JSON，相对路径按当前分析根目录解释。未设置保持原行为；设置为空、文件缺失/损坏/超过1MiB、格式错误、重复包或不安全仓库地址均失败。不得直接使用当前输出cjpm-provenance.json及其规范路径别名作为基线。包集合必须精确匹配，包括传递依赖，并比较version/repository/registry/sha256；数组顺序无关。拒绝时不下载本次仓库制品、不覆盖上次来源输出、不改批准文件。允许解析阶段访问/缓存元数据。

**Scope:** 不改求解器、lockfile或现有来源格式，不自动生成/批准基线，不提供签名、离线依赖快照、Git/本地依赖约束、已解包缓存真实性验证或构建脚本沙箱。受保护基线、工作目录、工具链和配置仍属于CI信任边界；独立脚本依赖的多次求解需另验。
